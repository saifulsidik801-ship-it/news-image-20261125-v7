The World in One Day — a front page of **Wednesday 25 November 2026**: 38 stories,
every one first reported on that day. Three heroes with large drawn scenes (US tariffs
up to 20%, the Asian chip crash, Pakistan's first astronaut), 13 numbered mid stories,
a 22-item list, a filled map with numbered pins, a UTC timeline strip, claim badges
(OFFICIAL / REPORTED / CLAIM / CONFIRMED) on every story, and a DATE CHECK box naming
the big stories left out because they belong to another day.

## Run it

```sh
python3 render.py && python3 main.py
```

`render.py` (stdlib + PIL only) draws `entry.png` (1024x1024). `main.py` copies it to
`$MAKEFUN_OUTPUT_DIR` (or `/output`).
